#ResumeAI – AI-Based Resume Screening and Job Matching System

📌 About the Project

ResumeAI is an AI-based resume screening and job matching application developed using Python. It helps candidates analyze their resumes, identify their skills, and find suitable job roles based on their qualifications.

The system extracts text from uploaded PDF and DOCX resumes and uses Natural Language Processing (NLP) techniques to compare candidate skills with predefined job requirements. It calculates a job compatibility score and recommends relevant job roles.

🚀 Features

- Upload resumes in PDF and DOCX formats.
- Automatic resume text extraction.
- Technical skill identification.
- Resume and job description matching.
- TF-IDF vectorization and cosine similarity.
- Matched and missing skills analysis.
- Top 5 job role recommendations.
- Resume compatibility score.
- Downloadable analysis report.

🛠️ Technologies Used

- Python
- Streamlit
- Natural Language Processing (NLP)
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- PyPDF2
- python-docx

⚙️ How It Works

1. Upload your resume.
2. Extract text from the resume.
3. Identify technical skills.
4. Compare skills with predefined job requirements.
5. Calculate the matching score.
6. Display suitable job recommendations.

🎯 Project Objective

To develop an AI-based system that simplifies resume screening, analyzes candidate skills, identifies skill gaps, and recommends suitable job opportunities.

💡 Future Improvements

- Advanced NLP models for better resume understanding.
- Support for multiple languages.

👨‍💻 Developed With

Python | Streamlit | Machine Learning | NLP

Note: The compatibility score is an estimated match based on the system's predefined skills and job descriptions. It is not a hiring probability or an official ATS score.
